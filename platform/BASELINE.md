# Baseline — дословно копие на DARYCARD

Тази папка е **изходната точка** на многофирмения TransitFlow. Съдържанието ѝ в
първия комит е копирано байт по байт от DARYCARD и **не е променяно с нищо**.
Всяка следваща промяна се вижда като diff спрямо този комит.

| | |
|---|---|
| Източник | `D:\DARY` |
| Комит на източника | `ba1b100c54b2e81af333a09c6ad0ef366775b81f` |
| Дата на комита | 22.08.2026 |
| Копирани файлове | 101 |
| Общ размер | 6,69 MB |

`BASELINE.manifest.json` съдържа SHA-256 на всеки копиран файл, изчислен върху
**оригинала в DARYCARD**. Проверка по всяко време:

```bash
cd platform && python -c "import json,hashlib,os; m=json.load(open('BASELINE.manifest.json',encoding='utf-8')); print(sum(hashlib.sha256(open(e['path'].replace('/',os.sep),'rb').read()).hexdigest()!=e['sha256'] for e in m), 'разлики')"
```

DARYCARD остава да работи самостоятелно — собствен репозиторий, собствен Firebase
проект (`darycard-6e8e7`) и собствен домейн. Двете системи не споделят нищо освен
произхода на този код.

## Какво следва

Според плана нищо в тази папка не се променя, докато не е готова инфраструктурата
(Фаза 2 — нов Firebase проект в европейски регион). Първите реални промени идват
във Фаза 3: слоят за фирмата.

Потвърдени решения, които водят следващите фази:

- Адрес на картите: `app.transitflow.org/t/{фирма}/client/{код}`
- Изцяло нов Firebase проект, европейски регион
- Модулите „Сигнали“ и „Наеми автобус“ отпадат — не влизат в системата
- Разчет: поне 10 фирми до края на 2026 г.
- Ново Android приложение с нов подписващ ключ
